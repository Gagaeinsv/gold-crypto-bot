## Крок 1 — Створити бота в Telegram і отримати токен

1. Відкрий Telegram і знайди бота **[@BotFather](https://t.me/BotFather)**
2. Натисни **Start** (або напиши `/start`)
3. Напиши команду:
   ```
   /newbot
   ```
4. BotFather запитає **назву** бота — напиши будь-яку, наприклад:
   ```
   Gaming News UA
   ```
5. Потім запитає **username** (логін) бота — він має закінчуватись на `bot`, наприклад:
   ```
   GamingNewsUA_bot
   ```
6. BotFather відповість повідомленням де буде рядок типу:
   ```
   Use this token to access the HTTP API:
   7412345678:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```
7. **Скопіюй цей токен** — це твій `GAMING_BOT_TOKEN`

> ⚠️ Нікому не показуй цей токен — через нього можна керувати ботом.

## Крок 2 — Додати бота до каналу і дізнатись ID каналу

### 2.1 Додати бота як адміністратора

1. Відкрий свій Telegram-канал
2. Натисни на назву каналу вгорі → **Управління каналом** → **Адміністратори**
3. Натисни **Додати адміністратора**
4. Знайди свого бота за username (наприклад `@GamingNewsUA_bot`)
5. Залиш увімкненим дозвіл **"Публікація повідомлень"**, решту можна вимкнути
6. Натисни **Зберегти**

### 2.2 Дізнатись ID каналу

**Якщо канал публічний** (є username типу `@gaming_ua_channel`):  
Просто використай його як є: `@gaming_ua_channel`

**Якщо канал приватний** (без username):  
1. Перейди на сайт **[web.telegram.org](https://web.telegram.org)**
2. Знайди свій канал у лівому меню та відкрий його
3. Подивись на адресний рядок браузера — там буде щось таке:
   ```
   https://web.telegram.org/a/#-1002345678901
   ```
4. Скопіюй число разом із мінусом: `-1002345678901` — це і є `GAMING_CHANNEL_ID`

## Крок 3 — Отримати Gemini API Key (для перекладу на українську)

Gemini — це AI від Google, який перекладає та переписує новини живою українською мовою.

1. Перейди на **[aistudio.google.com](https://aistudio.google.com/)**
2. Увійди через свій Google-акаунт (той самий що Gmail)
3. У верхньому правому куті натисни **"Get API key"**

   ![Get API key кнопка в правому верхньому куті](https://i.imgur.com/placeholder.png)

4. Натисни **"Create API key"**
5. Зі списку вибери **"Create API key in new project"**
6. Ключ з'явиться на екрані — виглядає так:
   ```
   AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
   ```
7. **Натисни кнопку копіювання** поруч з ключем — це твій `GEMINI_KEY`

> ✅ Безкоштовний ліміт Gemini Flash дуже великий — для новинного каналу вистачить з головою.  
> ⚠️ Не показуй цей ключ нікому.

## Крок 7 — Створити файл з ключами (.env)

1. Відкрий папку з ботом
2. Знайди файл **`.env.example`** — це шаблон
3. Зроби його **копію** і назви копію просто **`.env`** (без `.example`)

   > На Windows файл може не відображатись якщо він починається з крапки.  
   > Відкрий папку → вгорі "Вид" → увімкни "Приховані елементи"

4. Відкрий файл `.env` у будь-якому текстовому редакторі (Notepad, VS Code тощо)
5. Заповни свої ключі:

```env
GAMING_BOT_TOKEN=7412345678:AAFxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
GAMING_CHANNEL_ID=@твій_канал
GEMINI_KEY=AIzaSyXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
RAWG_API_KEY=a1b2c3d4e5f6xxxxxxxxxxxxxxxxxxxx
ADMIN_ID=123456789
```

> Де взяти свій `ADMIN_ID` (Telegram ID):  
> Напиши будь-що боту **[@userinfobot](https://t.me/userinfobot)** — він відповість твоїм ID.

6. Збережи файл

## Крок 9 — Тримати бота запущеним постійно

Бот працює поки відкритий термінал. Щоб він працював постійно:

### Варіант A: VPS / хостинг (рекомендовано)
Орендуй найдешевший VPS (від ~$3-5/місяць):
- **[hetzner.com](https://www.hetzner.com/)** — від €3.29/міс
- **[digitalocean.com](https://www.digitalocean.com/)** — від $4/міс
- **[contabo.com](https://contabo.com/)** — від €4.99/міс

На VPS запусти бота через `tmux` або `screen` щоб він не зупинявся:
```bash
tmux new -s gaming-bot
python3 gaming_bot.py
# Натисни Ctrl+B, потім D — від'єднаєшся від сесії, бот продовжує працювати
```

### Варіант B: власний комп'ютер (простіше для початку)
Просто залиш термінал відкритим поки комп увімкнений.

### Варіант C: Railway (безкоштовний хмарний хостинг)
1. Перейди на **[railway.app](https://railway.app/)**
2. Зареєструйся через GitHub
3. Натисни **"New Project"** → **"Deploy from GitHub repo"**
4. Вибери репозиторій
5. У налаштуваннях проєкту додай всі змінні з `.env` через розділ **"Variables"**
6. Railway автоматично запустить `python3 gaming_bot.py`

## Що буде публікуватись у каналі (v1.4.0+)

### Пріоритет: новини

Більшість постів — **ігрові новини** з великих сайтів (IGN, Kotaku, PC Gamer…). Текст українською (Gemini), з фото, з **прямим посиланням** на статтю внизу поста.

### Роздачі — рідко і з різних магазинів

| Правило | Значення |
|---------|----------|
| Між будь-якими постами | мінімум **6 годин** |
| Постів на добу | максимум **4** |
| Безкоштовних ігор на добу | максимум **1** |
| Безкоштовних ігор на тиждень | максимум **3** |
| Після роздачі | спочатку **3 новини**, потім знову можлива гра |
| Магазини | Epic, Steam, GOG, PlayStation, Xbox (не спам з itch/indiegala) |

Одна й та сама гра з GamerPower і Epic **не дублюється**.

### Релізи (якщо є RAWG ключ)

Іноді пост про гру, що виходить у найближчі 7 днів.

### Приклади постів

| Тип | Приклад |
|-----|---------|
| 🎮 Новина | «Xbox додає нові ігри до Game Pass…» + посилання на IGN |
| 🎁 Роздача | «Безкоштовно в Epic — …» + посилання на store.epicgames.com |
| 🚀 Реліз | «Реліз: … — дата виходу …» |

## Проблеми та їх вирішення

| Проблема | Причина | Рішення |
|---|---|---|
| `GAMING_BOT_TOKEN is not set` | Не створено `.env` або токен порожній | Перевір крок 7 |
| `Chat not found` | Бот не адмін в каналі | Перевір крок 2.1 |
| `Forbidden: bot is not a member` | Бот не доданий до каналу | Додай бота як адміна (крок 2.1) |
| Пости англійською | `GEMINI_KEY` не вказаний | Додай ключ у `.env` (крок 3) |
| `pip: command not found` | Python не в PATH | Перевстанови Python з галочкою "Add to PATH" |
| Купа безкоштовних ігор підряд | Стара версія бота | Онови до **v1.4.0**, видали `gaming_bot.db` |
| Бите посилання | Стара версія або обрізаний HTML | Онови до **v1.3.0+**; посилання має бути окремим рядком `https://...` |
| Немає `v1.4.0` у логу | Не той файл `gaming_bot.py` | Завантаж з GitHub (крок 6, варіант A) |
