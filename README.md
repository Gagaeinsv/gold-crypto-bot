# Ігровий Telegram-бот для новин

Автоматично публікує в Telegram-канал:

- ігрові новини (IGN, Kotaku, PC Gamer та ін.);
- безкоштовні роздачі (Epic Games, Steam, GamerPower);
- дати виходу ігор (RAWG API, опційно).

Пости українською через **Gemini AI**, з фото.

## Швидкий старт

```bash
pip install -r requirements.txt
cp .env.example .env
# заповни .env
python3 gaming_bot.py
```
